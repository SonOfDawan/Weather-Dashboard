## About the Project

The Weather Dashboard is a simple web application for viewing current weather conditions by city. It presents weather information in a clear, responsive interface that is easy to use on desktop and mobile devices.

Users can search for a city and view its temperature, weather conditions, humidity, wind speed, feels-like temperature, coordinates, and local observation time. The project also includes About and Contact pages.

## Features

- City weather search
- Current weather information display
- Responsive layout
- Input validation and user-friendly messages
- Handling for unavailable cities and connection errors
- About and Contact pages

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Open-Meteo weather data

## Project Structure

```text
index.html       Main weather dashboard
about.html       About page
contact.html     Contact page
css/style.css    Project styling
js/main.js       Weather search and page interactions
```

## Limitations

- Live weather information requires internet access.
- The Contact page is a frontend demonstration and does not send messages to a server.
- The dashboard displays current conditions rather than a long-term forecast.

## Attribution
