About this project

Useful weather information, kept simple.

The Weather Dashboard Web Application is a Week 10 SIWES mini-project built by Plangji Solomon Dawan from Miva Open University during virtual training with Defems Technologies.

The problem

People need a quick way to check current conditions before planning travel, work or daily activities. This project turns live weather data into a clear, readable dashboard instead of requiring users to understand an API response.

Project objectives

  • Practise semantic HTML and accessible page structure.
  • Build responsive layouts with modern CSS.
  • Use JavaScript to call and process JSON from REST APIs.
  • Handle validation, loading states and failures responsibly.

Technologies

HTML5 provides structure, CSS3 provides the visual design and responsive layout, and vanilla JavaScript controls search, API requests and updates to the page.

How the APIs work

The Geocoding API first changes a city name into coordinates. Those coordinates are then sent to the Weather Forecast API, which returns current temperature, humidity, wind and weather-code data as JSON.

Data source: Open-Meteo.
